# 验证记录

日期：2026-09-30。对象：本仓库五个独立技能及其模板、界面元数据和使用说明。

## 结构与包装

五个技能均通过 skill-creator 的 `quick_validate.py`。另行检查了名称与目录一致性、YAML 元数据、默认调用提示、自动发现设置、引用可定位且不依赖其他技能目录、README 链接和未完成脚手架标记。

这些检查确认文件结构与引用完整，不证明模型在任意请求下都会正确触发或执行技能。未在其他工具中实际安装验证。

## 独立场景试用

评估者仅依据技能及虚构的中性原始材料生成报告，再由审查核对实际输出。场景不包含真实业务代码或生产访问。

| 技能 | 关键场景 | 观察结果 |
| --- | --- | --- |
| `legacy-spec-distillation` | 归档协议适用性未知，代码与测试行为冲突，另有明确批准的变更，缺少执行记录 | 交付五项逻辑产物；冲突保持“尚待确认”；已批准变更可继续；没有把测试定义写成通过记录 |
| `spec-driven-rewrite` | 外部自然语言规格、旧测试预期与批准变更冲突、另一行为未决 | 接受既有规格；保留有效业务断言；按批准目标规划测试适配；仅阻塞未决行为的相关范围 |
| `rewrite-parity-audit` | 已批准变化、真实回归、共同遗留缺陷和未决规则并存 | 区分行为差异与质量问题；不把旧版相同当作安全证明；未将静态线索扩大为已证实的安全影响 |
| `rewrite-release-validation` | 主流程 E2E 摘要通过，但通知数量异常、隔离未知，迁移增量与回退缺证据 | 保留局部结果；不判定整体可切换；列明副作用、恢复与回退的证据缺口 |
| `rewrite-stabilization` | 延迟下降伴随负载下降、错误率上升，尚无持续监控 | 不宣称已证明性能改善；优先调查错误；把采集、修复与观察写成待执行工作，不虚称已监控 |

初始蒸馏场景对协议权威性存在歧义，因此补充了“归档协议适用性明确未知”的场景。原场景不能作为技能改善效果的明确证据。其他无技能基线在多项关键判断上也已表现正确；本轮评估用于检查符合性与输出边界，不宣称测得相对提升。

## 审查修订

逐项及整包审查后，已落实以下修订并完成相应复核：

- 蒸馏结论关联证据适用范围，五项产物通过稳定编号互相追踪。
- 发布与稳定技能独立保留行为、问题和结论编号，贯穿修复、复验与交接。
- 审计明确区分本次执行、可核查的既有报告和只有摘要的观察。
- 可能影响外部系统的验证先检查授权、副作用与隔离，再执行相关测试。
- 五项触发描述同时包含中英文场景表达。

最终独立审查无未关闭的发布前修复项。最后文本修改后的结构与包装检查通过。

## 验证边界

本轮是技能文档的结构检查、合成材料试用和独立审查，没有实施真实项目重写，也没有运行真实项目 E2E、迁移、发布或持续监控。中文与英文的真实自动触发率、大规模代码提取完整性、长期使用效果及实际性能收益尚未测量。

用于具体项目时，仍需记录该项目的版本、证据、验收条件与实际执行结果；不能把此记录作为项目发布依据。
