# 入口面清单

能力普查按下表逐类过一遍：每类先列出具体实例，再把每个实例归入交付、待定或不交付。

顺着业务主线提取，容易漏掉不在主线上的能力，比如连接安全、断线补发、启动恢复、运维命令、容量上限。这张表就是用来兜住它们的。

| 入口面 | 列出什么 | 易漏点 |
| --- | --- | --- |
| 外部协议 | 每种请求、响应、事件、错误码与时序；重连与补发行为 | 断线期间产生的结果如何送达；重复请求的幂等范围 |
| 配置与数据结构 | 每个字段、Schema 枚举值、可选字段与默认值 | 字段被校验、保存、回读，不等于运行时生效。要核对运行代码是否真的读取它 |
| 对外命令与接口 | HTTP / RPC 端点、CLI 与运维命令、管理工具 | 只有运维会用的命令（启停、状态、应急改配置） |
| 扩展点 | 插件接口、可选入口、声明格式、版本标识 | 接口里保留着、却没有任何调用方或数据来源的入口；契约和代码里同名的能力语义不同（例：契约里是"连入后轮询"，代码里是"设备推送"） |
| 连接与安全 | TLS、认证、凭据、证书、网口或地址绑定 | 配置了安全选项但运行时未使用 |
| 部署与启动 | 安装与升级脚本、开机自启顺序、依赖服务（时钟同步、网络） | 业务正确性依赖的部署前提，比如采样时间依赖开机校时 |
| 后台与周期任务 | 心跳、重试与退避、清理、轮转、定时器 | 服务带故障启动时的行为；重启上限 |
| 持久化与恢复 | 启动恢复、损坏处理、事务日志、缓存预算与淘汰 | 未完成事务每个中间状态的恢复判据；预算用尽时丢新还是丢旧 |
| 容量与限额 | 常量、缓冲区、帧或包大小、Schema 上限 | 契约上限与实现上限逐项对照，不一致开成待确认 |
| 可观测 | 日志策略、指标、诊断与调试工具 | 诊断与调试工具是否属于产品能力，按已确认范围判定；依据不足归待定 |
| 残留 | 只解析不调用的代码、受理时就拒绝的分支、枚举里未实现的值 | 归为不交付并写明依据，免得后人把残留"补齐" |

完成：每类至少写明"无"或列出实例；每个实例都有归类和证据编号。
